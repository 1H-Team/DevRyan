- `final-evidence-rules.mjs` validates recorded-cwd journal-gap directory identity
  for the exact `gaps --dir <root>` and `--dir <root> gaps --verify` spellings
  (the result reports which) and independently pinned raw-hash summary projections. It classifies only a
  scenario-declared user Stop joined to bounded canonical journal IDs and a later
  successful turn; all other raw errors remain unexpected. Historical undeclared
  failures are not regraded.
- `package-electron.mjs` pins the freshly bundled main file's raw bytes and full
  input closure, verifies them again after packaging, and retains the receipt
  beside the original package evidence.
- `packaged-bundle-recovery.mjs` launches the fresh packaged main/preload against
  an original held transition with a separate private Chromium harness. It checks
  recovery-only HTTP, strict trusted IPC refusals, unchanged retained candidate
  and proof, and owned-process cleanup. Native dialog cancellation requires an
  actual trusted-input callback and the original IPC cancellation response.

Repository-only Electron/web QA and shared CDP inspection helpers. No file in this directory enters the shipped UI or changes native security policy.

- `launch-environment.mjs`: one explicit platform-input allowlist for prepared
  live profiles, fixture QA, matrix hosts and resource benchmarks. Credentials,
  proxy/preload options, runtime flags and personal account paths never flow
  from the invoking shell. Owned profile values and explicit host overrides
  supply runtime configuration; `isolated-host.mjs` supplies the reviewed
  private credential projection. Live matrix `mirrorPersonalSetup` accepts
  the profile's boolean/explicit plugins-skills-MCP options only alongside
  `preserveOrchestration`; expansion and `prepareQaMatrixLiveProfile` retain
  these choices through the actual profile-builder call.

- `terminal-cleanup.mjs`: opt-in native POSIX PTY stop/restart/shutdown check.
  Disposable shells and children resistant to SIGHUP/SIGTERM live under
  `.cache/qa`; an unrelated sentinel must survive every cleanup. Unsupported
  platforms fail as unavailable. Run
  with `bun scripts/qa/terminal-cleanup.mjs`; no installed runtime is accessed.
