# Disposable review workbench

This project is an isolated coding fixture. Implement only the current approved brief and preserve earlier completed requirements.

Run the real test suite with bun test. React and React DOM are already linked from the repository's installed dependencies; do not install packages or change dependency manifests.

Editable files: review-domain.ts, the four Review*.tsx components, review-workbench.css and review-workbench.test.tsx. Preserve review-data.ts, package.json, tsconfig.json and this README. Do not edit files outside this project.

The interfaces in review-domain.ts and ReviewWorkbenchProps are the shared contract. Add the named exports requested in each brief. Preserve input arrays and unchanged review references where the brief requires immutable updates.
