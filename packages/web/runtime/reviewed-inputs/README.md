# Reviewed runtime inputs

These are exact repository-owned captures of already selected package versions, retained with their package metadata and captured licenses. Production must use static compiled inputs or verified executable assets; it must never import their original `.cache` locations or mutable user `node_modules`.

The 197 MB Claude executable exceeds GitHub's source-file limit and is excluded from Git. Before a fresh native build, run `node scripts/hydrate-reviewed-claude.mjs`. It downloads the exact selected public npm archive, verifies its pinned SHA-512 integrity and the captured executable's SHA-256 and size, and installs the executable without overwriting an existing file. CI performs this step before building; the existing manifest and signature checks still apply.

Actual pure command factories and the original interview state machine remain reusable through constructor callbacks; original interview document operations are worker-only exports.
