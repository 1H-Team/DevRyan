DevRyan is the visual workspace around OpenCode.

Use these docs to:

- install the right surface for your workflow

- customize appearance and troubleshoot common issues

## What DevRyan is for

DevRyan is for the parts of AI coding that benefit from a control room: branching sessions, reviewing diffs, managing terminals, watching tool progress, running project actions, and keeping the full board visible while the agent works.
