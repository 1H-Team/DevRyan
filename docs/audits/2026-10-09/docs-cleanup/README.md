# Documentation cleanup

Branch `docs/cleanup-2026-10`, from `main` at `de104648` (v2.0.4). One commit per phase.

The repository's Markdown had grown in three ways. Finished plans were still kept as live guidance. Codemaps generated by a codemap skill that is no longer used had become append-only change logs. The evidence tree had reached 40 MB of screenshots and raw JSON. Several "current" documents still described OpenCode 1.18.x or 2.0.20 as the runtime in use, and nothing stopped any of this from growing back.

## What changed

1. **Dead trees.** These were deleted:
   - `docs/superpowers/`, the force-tracked `.superpowers/sdd/task-4-report.md`, `implementation-plan.md` and `BACKPORT.md`. The two still-true backport divergences are now comments in `formatters.js` and `output-replay-buffer.js`.
   - The OpenCode 1.15–1.18.27 upgrade notes.
   - `docs/REVERSE_PROXY.md` and `docs/CUSTOM_THEMES.md`, now covered by `packages/docs`.

   The model-switch handoff budgets moved to `packages/ui/src/sync/DOCUMENTATION.md`.
2. **Audit pruning.**
   - Deleted 35 entries that nothing outside `docs/audits` cited, about 18.5 MB. Among them: `2026-09-07-bot-simplification`, `2026-09-08-session-changes-attribution`, `2026-09-07-repository-maintenance`, `2026-10-02-opencode-v2-performance` and `2026-10-05-opencode-v2-handoff`, plus 18 loose reports.
   - Removed raw dumps from kept entries: baseline `cache-usage` and parity manifests, serializer probes, `failed/` payloads, videos and scripts.
   - Removed byte-identical duplicates.
   - Replaced local home paths with `<HOME>`.
   - Converted the small 2026-10-09 JSONL summaries to JSON arrays.
3. **Archived plans.** Finished plans and verification reports moved from `docs/` into dated `docs/audits/<date>/<slug>/` entries, each with an archive banner. Per-version logs and qualification history also moved out of `PROVIDER_RECOVERY`, `WINDOWS_PORT_PLAN`, `QA` and the Tauri cutover record.
4. **Stale claims.**
   - Removed environment variables and a workflow that no longer exist.
   - Stopped describing 1.18.x as the current runtime.
   - `PROVIDER_RECOVERY` now names the native recovery policy constants.
   - Cut the inherited pre-reset `CHANGELOG.md` tail (everything from `[1.1.12]` below `[1.0.0]`) and three measurement-dump entries.
   - Replaced the upstream desktop README with a legacy stub.
5. **Codemaps removed.** All 167 non-vendored `codemap.md` files and the root `CODEMAP.md` are deleted; the full list is in that phase's commit. `AGENTS.md` now points at package manifests and module `DOCUMENTATION.md` files. The v2 projection semantic-loss register, which `LOSS(key)` source comments refer to, moved to `packages/web/server/lib/opencode/v2/DOCUMENTATION.md`.
6. **Guardrails.** `bun run docs:validate` now runs `scripts/docs/doc-retention.mjs` and fails on any of these:
   - any `codemap.md` or `CODEMAP.md` outside `packages/web/runtime/reviewed-inputs/`;
   - a `docs/audits/<date>/<slug>/` entry without `README.md`;
   - `.jsonl`, `.log`, `.webm`, `.mp4` or `.mjs` files under `docs/audits`;
   - an audit file over 200 KB, except the hash-pinned `live-acceptance.json` files in `AUDIT_PINNED_EVIDENCE`;
   - a new-layout audit entry that `CHANGELOG.md`, a top-level `docs/*.md` or a `DOCUMENTATION.md` does not cite.

   The rules are summarized in `docs/TESTING.md`.

## Deliberately kept

- The six `live-acceptance.json` files that `harness-duplicate-qualification.test.js` checks by SHA-256. They are byte-identical, and the test passes.
- Uncited audits that back in-flight work: `2026-09-26-slim-2.2.24`, `2026-09-28-appearance-settings.md`, `2026-09-28-slim-2.2.25`, `2026-09-29-worker-browsers.md`, `2026-10-05-release-2.0.1.md` and `2026-10-08/`. Also kept are `2026-09-08-plugin-upgrades` and `2026-09-25-simple-task-latency.md`, because kept entries link to them.
- Runtime assets that look like documentation: `packages/web/server/default-config` agent and skill prompts, `packages/desktop/src-tauri/resources`, `packages/web/runtime/reviewed-inputs` (including the vendored codemap skill), `.opencode/README.md`, and the prompt files under `packages/ui/src/components`. The bundled Explorer, Builder, Fixer and Orchestrator prompts still mention codemaps as an optional lead in user projects. They were not changed, because they are shipped prompt assets.
- Release-note extraction: the `release.yml` extractor still finds notes for `2.0.4`, `2.0.3` and `1.0.0`.

## Verification

- `bun run docs:validate`: passed with 215 documents, 770 references and 14 warnings. Every warning is a missing link inside historical audits or a generated build target.
- `VALIDATE_BASE=main bun run validate:affected` widened to full validation. Lint, type-check and `docs:validate` passed.
- `test:scripts`: everything passed except `scripts/opencode-v2-native/native-browser-worker.test.mjs` (3 tests). It needs the built `packages/web/runtime/darwin-arm64` execution launcher, which this clean worktree does not have.
- Each package suite was then run on its own, with the hydrated Claude binary copied in for the run.
  - Passed: `bots-runtime`, `bot-supervisor`, `bot-engine-proxy`, `bot-egress`, `bot-computer`, `bot-indexer`, `bot-db`, `shared-runtime`, `harness-runtime`, `orchestration-runtime`, `cursor-sdk-runtime`, `electron`, `ui`, and `web` (6,544 tests passed, 1 skipped).
  - `desktop` could not build: its Cargo build needs the `sidecars/openchamber-server-*` resource, which is build output.
- `harness-duplicate-qualification.test.js` passed, so the six pinned files are unchanged.
