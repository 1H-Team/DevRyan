# DevRyan resource and harness improvements — 2026-09-20

## Scope and status

Implementation follows the approved ten-opportunity plan. Public HTTP/SSE/WebSocket payloads, ledger format, UI hooks, model selections and runtime ownership remain compatible. No dependency was added, upstream checkout was accessed, or legacy Tauri feature changed. The working tree also contains unrelated user work; this report describes the changes for this plan rather than treating the whole diff as one change.

The resource mechanisms and comparison tooling are implemented. The fresh native evaluation attempts are closed, but acceptance remains **unqualified**: neither compaction journey reached its required first boundary. The five independent policy/role comparisons were not run because the native prerequisites failed. Defaults remain unchanged. Local correctness, synthetic resource measurements and native fixture behavior are separate evidence classes.

Whole-worker heap after forced GC increased slightly: 5,946,688 → 5,959,296 bytes for the ledger case and 10,443,616 → 10,469,488 bytes for vector retrieval. These measurements do not establish a retained-memory improvement. The CI gate uses correctness and work counts rather than machine-dependent timing thresholds.

The compact role candidate is 33,191 bytes versus 40,312 bytes for the packaged role, a 17.7% reduction in persistent source size. Its on-demand guide is 9,751 bytes. This is **not** a measured input-token, cost or successful-task improvement.
